# User Interface Overview

The user interface is divided into three parts:

![The Budget view with the sidebar, the budget and the top right corner labeled](/img/a-tour-of-actual/tour-user-interface-overview@2x.webp)

Standard on most screens:

- **A. Sidebar.** The left sidebar lets you easily switch between the various views, such as Budget, Reports, and Accounts.
- **B. Content.** The content of the rest of the interface depends on the view you have chosen in the sidebar. This screenshot shows an example of a Budget view.
- **C. Top right corner.** The server status (if used) is shown in the upper right corner.

## Top Right Corner

<img width="286" alt="The top right corner with the privacy, notifications, sync, server status and Help buttons labeled" src="/img/elements/top-bar/top-right@2x.webp" />

- **A. Privacy.** The eye icon will scramble the numbers on the screen. This is useful if you need to report a bug to the Actual team but want to keep your numbers private. There are some caveats to this, so please read [Scramble and Hide Data](../getting-started/tips-tricks.md#scramble-hide) in the Tips & Tricks guide.
- **B. Notifications.** The bell opens the [Notifications](../notifications.md) page with release notes and announcements from the Actual project.
- **C. Sync.** Clicking on the refresh icon will force a sync of your local file to the server. Note: it does **not** perform a bank sync. It's only shown when you use a server.
- **D. Server status.** _Server online_ shows the server is connected, _Server offline_ shows the server is disconnected, and _No server_ shows if you are not using a server. If you click on this text a server menu pops up.
- **E. Help.** The farthest right item is a Help menu.

## The Sidebar

The sidebar is how you move between the main parts of Actual.

<img width="261" alt="The sidebar with the navigation links, Settings and the accounts list labeled" src="/img/a-tour-of-actual/tour-user-interface-sidebar@2x.webp" />

- **A. Navigation.** The menu at the top links to your Budget, Reports and Schedules. Less used pages, like Payees, Rules and Tags, are in Settings. The [Sidebar](../settings/index.md#sidebar) section of the settings lets you choose which pages appear in the menu.
- **B. Settings.** Settings is at the bottom of the menu.
- **C. Accounts.** Below the menu are all of your accounts, both on budget and off budget, listed under their respective heading.

Most of these we will cover later in the tour.
