This patch release fixes several security vulnerabilities. We recommend updating your Actual server and desktop app, along with the API package if you use it.

After changing your server password, you will need to sign in again on your other devices. Changing the password now also requires your current password.

## Security Fixes

- Reject invalid password inputs when setting up or signing in to a server. [GHSA-3jjw-2hq7-mmm2](https://github.com/actualbudget/actual/security/advisories/GHSA-3jjw-2hq7-mmm2)
- Require the current password before allowing a server password change. [GHSA-4wgp-48c6-v9w3](https://github.com/actualbudget/actual/security/advisories/GHSA-4wgp-48c6-v9w3)
- Revoke existing password sessions when the server password changes. Also revoke sessions when signing out or shutting down an API connection that signed in with a password. [GHSA-7363-3qq5-2frj](https://github.com/actualbudget/actual/security/advisories/GHSA-7363-3qq5-2frj)
- Require administrator permissions to configure Enable Banking. [GHSA-hfxx-qc34-gqcw](https://github.com/actualbudget/actual/security/advisories/GHSA-hfxx-qc34-gqcw)
- Keep authentication secrets and sensitive provider responses out of ordinary server logs, while preserving detailed diagnostics through the existing opt-in sensitive logging setting. [GHSA-ppcp-hx2h-fm35](https://github.com/actualbudget/actual/security/advisories/GHSA-ppcp-hx2h-fm35)
- Block unsafe network destinations when connecting to external services. [GHSA-97j5-6g5r-42v5](https://github.com/actualbudget/actual/security/advisories/GHSA-97j5-6g5r-42v5)
- Prevent imported or downloaded budgets from overwriting unrelated local budgets. [GHSA-7fr5-fjj8-hwjq](https://github.com/actualbudget/actual/security/advisories/GHSA-7fr5-fjj8-hwjq)
- Restrict desktop links to web addresses, prevent untrusted pages from accessing desktop-only actions, and block network paths in the file-manager action. [GHSA-7pf2-w24j-p6h2](https://github.com/actualbudget/actual/security/advisories/GHSA-7pf2-w24j-p6h2)
- Prevent specially crafted Commerzbank payee names from stalling bank imports. [GHSA-p34v-m2gp-w3jm](https://github.com/actualbudget/actual/security/advisories/GHSA-p34v-m2gp-w3jm)
- Prevent formulas hidden behind invisible characters from running when exported CSV files are opened in a spreadsheet. [GHSA-7jvc-qfpw-85g2](https://github.com/actualbudget/actual/security/advisories/GHSA-7jvc-qfpw-85g2)
