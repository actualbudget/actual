## 快速开始

Actual 是一款本地优先（local-first）的个人理财工具。它 100% 免费且开源，使用 NodeJS 编写，并内置同步能力：你的所有更改都能在设备之间轻松流转，无需任何繁琐操作。

如果你有兴趣参与贡献，或想了解开发是如何进行的，请参阅我们的[贡献指南](https://actualbudget.org/docs/contributing/)，非常欢迎你的加入。

## 安装

Actual 提供四种部署方式：

1. [通过 PikaPods](https://www.pikapods.com/pods?run=actual) 一键部署（约 2.00 美元/月）——推荐给非技术用户
1. [通过 Fly.io](https://actualbudget.org/docs/install/fly) 托管（约 1.50 美元/月）
1. 使用 [Docker 镜像](https://actualbudget.org/docs/install/docker) 自托管
1. 纯本地应用——[下载 Windows、Mac 和 Linux 客户端](https://actualbudget.org/download/)，在你自己的设备上运行

更多细节请参阅[安装说明文档](https://actualbudget.org/docs/install/)。

### 代码结构

Actual 应用由以下几个包组成：

- loot-core——可在任意平台运行的核心应用
- desktop-client——桌面端界面
- desktop-electron——桌面应用

更多项目结构说明请参阅我们的[社区文档](https://actualbudget.org/docs/contributing/project-details)。

### 功能需求

当前的功能需求可以[在此查看](https://github.com/actualbudget/actual/issues?q=is%3Aissue+label%3A%22needs+votes%22+sort%3Areactions-%2B1-desc)。
